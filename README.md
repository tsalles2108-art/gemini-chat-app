# Gemini Chat App

Website para acessar Google Gemini com funcionalidades de chat e análise de documentos.

## 🚀 Quick Start

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend (novo terminal)
cd frontend
npm install
npm start
```

Acesse em `http://localhost:3000`

## 🔧 Configuração

A chave de API Google Gemini está configurada em `backend/.env`
